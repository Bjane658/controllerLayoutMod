# ControllerLayoutMod

This is a mod for [AlchemistsAlcove](https://store.steampowered.com/app/3568090/Alchemists_Alcove/) that changes the controller layout with custom bindings.

More infos on modding AlchemistsAlcov can be found [here](https://github.com/FartFish/AlchemistsAlcoveExampleMods/tree/main)

Currently it just overrides the default bindings with the bindings found in `custom_action_bindings` from `controller_layout.gd`.

### changed bindings

move: Left Stick

inventory: D-Pad

notebook: Right Stick

Other bindings remain the same, but can be changed aswell.
Just add the action and it's custom binding to `custom_action_bindings`

### planned features
* A controller settings menu to change bindings within the game.
